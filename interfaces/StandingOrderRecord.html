    Interface StandingOrderRecord

    A standing order this wallet published, tracked locally so the coins it commits are not offered again while it is live. The network's order cache refuses a second order spending an input of a stored order ("order rejected (expired, duplicate, or input conflict)"), and evicts an order only when it expires or one of its inputs is spent on chain.
